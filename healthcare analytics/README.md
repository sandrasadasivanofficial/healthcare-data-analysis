# Healthcare Data Analysis
------------------------

## Project Overview
-------------------
This project focuses on analyzing healthcare data to identify useful insights about patients, medical conditions, admissions, billing, and insurance providers.

The project includes Exploratory Data Analysis (EDA) using Python, SQL analysis using MySQL, and data visualization using Power BI.

## Tools and Technologies
-------------------------
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* MySQL
* Power BI
* Jupyter Notebook

## Exploratory Data Analysis
---------------------------
The EDA part includes:

* Data loading and inspection
* Data cleaning
* Handling missing values
* Statistical analysis
* Patient demographics analysis
* Medical condition analysis
* Billing analysis
* Data visualization

## SQL Analysis
---------------
The SQL analysis was performed using MySQL.

Topics covered include:

* Filtering data using WHERE
* Sorting using ORDER BY
* Grouping using GROUP BY
* Filtering groups using HAVING
* Aggregate functions such as COUNT(), SUM(), AVG(), MAX(), and MIN()
* Healthcare-related business questions and analysis

## Power BI Visualization
---------------------------
Power BI was used to create visualizations for:

* Total number of patients
* Average patient age
* Patients by gender
* Patients by blood type
* Billing amount by admission date
* Billing amount by medical condition and admission type
* Billing amount by medical condition
* Insurance provider analysis
* Maximum billing amount by insurance provider

## Key Project Insights
----------------------
* The dataset contains approximately 55,500 patient records.
* The average patient age is approximately 51.54 years.
* Patient records include different genders and blood types, allowing demographic analysis.
* Medical conditions were analyzed to understand patient distribution and billing patterns.
* Billing amounts were analyzed across medical conditions and admission types such as Elective, Emergency, and Urgent.
* Billing amounts were compared across different insurance providers.
* UnitedHealthcare was identified as the last insurance provider in the Power BI analysis.
* Admission dates were analyzed to identify billing trends over time.
* Power BI visualizations helped present patient demographics, medical conditions, admission information, billing, and insurance-related insights.

## Project Objective
-------------------
The main objective of this project is to practice the complete data analysis process:

Data → Cleaning → Analysis → Visualization → Insights

The project demonstrates how Python, SQL, and Power BI can be used together to analyze healthcare data and present meaningful information.
